# Inbox

Drop a CSV of comments here (one comment per row, in a column named `comment`, `text`, `body`, `message` or `content`)
and push it to GitHub. The **Auto triage** workflow then sorts the comments and writes a report and a sorted CSV to
`reports/auto/`, with no one running anything.

`sample_comments.csv` is **synthetic demo data written for this project** (not real people's comments).
